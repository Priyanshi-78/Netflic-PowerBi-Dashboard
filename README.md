# Netflic-PowerBi-Dashboard
# 🎬 Netflix Power BI Dashboard

## Overview
This is my first Power BI dashboard project built using the Netflix Titles dataset. The dashboard provides interactive visualizations to analyze Netflix content, including movies, TV shows, ratings, genres, release years, and countries.

## Dashboard Features

- Movies vs TV Shows Distribution
- Content Released Over Years
- Top Countries by Content
- Content Rating Distribution
- Top Genres
- Movie Duration Distribution
- Top Directors
- Interactive Filters (Content Type, Country, Rating)

## Key Insights

- Movies make up the majority of Netflix content.
- Most content has been released in recent years.
- TV-MA is one of the most common content ratings.
- A few countries contribute the highest amount of Netflix content.
- Drama and Comedy are among the most popular genres.
